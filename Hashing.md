# Hashing

Hashing converts a **key into an index of an array** using a function called a **hash function**.

## Important Components of Hashing

### 1️⃣ Key
The value used to identify data.  
**Example:**  
- Student ID
- Roll Number
- Email
- Phone Number

### 2️⃣ Hash Function
A **function that converts a key into an index** of an array.
**Example:**  
h(key) = key % table_size

### 3️⃣ Hash Table
A data structure that stores data using the index generated by the hash function.   
It is basically an **array**.


## Time Complexity (Average Case)
| Operation |	Time Complexity |
|-----------|-----------------|
| Insertion |	O(1) |
| Deletion  | O(1) |
| Searching	| O(1) |

Worst case becomes **O(n)** when many collisions occur.


## Hash Collision
When **two keys produce the same index**, it is called **collision**.



## Advantages of Hashing
✔ Very fast searching  
✔ Direct access to data  
✔ Efficient for large datasets  

## Disadvantages of Hashing
❌ Collision problem   
❌ Extra memory required   
❌ Performance depends on hash function
